## Question

Calculate (a) the number of moles in 10 g of sodium hydroxide, NaOH, and (b) the number of formula units it contains. [H = 1, O = 16, Na = 23; Avogadro constant = 6.02 x 10^23 per mole]

## Solution

1. First find the molar mass by adding the relative atomic masses of the atoms in the formula.
2. Molar mass of NaOH = 23 + 16 + 1 = 40 g/mol.
3. Part (a). Number of moles = mass in grams / molar mass in g/mol.
4. Number of moles = 10 / 40 = 0.25 mol.
5. Part (b). One mole contains the Avogadro number of formula units, 6.02 x 10^23 per mole, so multiply the moles by it.
6. Formula units = 0.25 x 6.02 x 10^23 = 1.505 x 10^23.
7. NaOH is ionic, so these are formula units, not molecules. Each one supplies one Na+ ion and one OH- ion in solution.

**Answer: (a) 0.25 mol  (b) 1.505 x 10^23 formula units**
