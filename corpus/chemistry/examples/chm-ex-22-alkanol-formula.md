## Question

(a) An alkanol has a relative molecular mass of 46. (b) An alkanoic acid has a relative molecular mass of 60. Determine the molecular formula and the name of each. [H = 1, C = 12, O = 16]

## Solution

1. As with the hydrocarbons, start from the general formula of the series and write its relative molecular mass in terms of n.
2. Part (a). An alkanol is CnH2n+1OH, which is the same as CnH2n+2O, so its mass is (12n) + (2n + 2) + 16 = 12n + 2n + 2 + 16 = 14n + 18.
3. 14n + 18 = 46, so 14n = 28 and n = 2.
4. With n = 2 the formula is C2H5OH, which is ethanol.
5. Part (b). An alkanoic acid is CnH2n+1COOH, which is the same as CnH2nO2, so its mass is 12n + 2n + (2 x 16) = 14n + 32. The carbon of the -COOH group is counted in n.
6. 14n + 32 = 60, so 14n = 28 and n = 2.
7. With n = 2 the formula is C2H4O2, written out as CH3COOH, which is ethanoic acid.
8. Check both. C2H5OH: (2 x 12) + (6 x 1) + 16 = 46. C2H4O2: (2 x 12) + (4 x 1) + (2 x 16) = 60.
9. Note that an alkanol and an alkanoic acid can share a relative molecular mass: 46 fits ethanol and also fits HCOOH, methanoic acid. The mass alone does not settle which family a compound belongs to; the functional group does.

**Answer: (a) C2H5OH, ethanol  (b) C2H4O2, that is CH3COOH, ethanoic acid**
