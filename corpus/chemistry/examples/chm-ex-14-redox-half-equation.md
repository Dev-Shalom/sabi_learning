## Question

In acid solution the heptaoxodichromate(VI) ion, Cr2O7 2-, is reduced to the chromium(III) ion, Cr3+. Write the balanced half-equation for this reduction.

## Solution

1. Work through the standard order: balance the atoms other than oxygen and hydrogen, then add water for the oxygen, then hydrogen ions for the hydrogen, then electrons to balance the charge.
2. Chromium first. There are 2 chromium atoms on the left, so write 2Cr3+ on the right.
3. Cr2O7 2- -> 2Cr3+
4. Oxygen next. There are 7 oxygen atoms on the left, so add 7H2O on the right.
5. Cr2O7 2- -> 2Cr3+ + 7H2O
6. Hydrogen next. 7H2O contains 14 hydrogen atoms, so add 14H+ on the left. The solution is acidic, so hydrogen ions are available.
7. Cr2O7 2- + 14H+ -> 2Cr3+ + 7H2O
8. Now the charge. Left: (-2) + (+14) = +12. Right: 2 x (+3) = +6.
9. The left is more positive by 6, so add 6e- to the left.
10. Cr2O7 2- + 14H+ + 6e- -> 2Cr3+ + 7H2O
11. Check it against the oxidation numbers. In Cr2O7 2-, 2x + 7(-2) = -2 gives x = +6. Each chromium falls from +6 to +3, a gain of 3 electrons, and there are 2 of them, so 6 electrons in all. The two methods agree.

**Answer: Cr2O7 2- + 14H+ + 6e- -> 2Cr3+ + 7H2O**
