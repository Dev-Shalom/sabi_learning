## Question

Simplify (root 12 + root 27) divided by root 3.

## Solution

1. Simplify each surd in the numerator by taking out the largest perfect square.
   root 12 = root(4 times 3) = 2 root 3.
   root 27 = root(9 times 3) = 3 root 3.
2. Add the like surds: 2 root 3 + 3 root 3 = 5 root 3.
3. Divide: 5 root 3 divided by root 3 = 5.

**Answer: 5.**

## Note

The answer is a whole number even though the question is full of surds. Always
simplify each surd first; the cancellation usually appears only after that.
