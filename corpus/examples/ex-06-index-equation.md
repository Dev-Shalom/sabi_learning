## Question

Solve for x: 2^(2x + 1) = 32.

## Solution

1. Write the right-hand side as a power of the same base. 32 = 2^5.
2. So 2^(2x + 1) = 2^5.
3. When the bases are equal, the powers are equal: 2x + 1 = 5.
4. 2x = 4, so x = 2.

**Answer: x = 2.**

## Check

2^(2 times 2 + 1) = 2^5 = 32, which matches the right-hand side.
