## Question

Find the turning points of the curve y = x^3 - 3x^2 - 9x + 5 and determine whether
each is a maximum or a minimum.

## Solution

1. Differentiate: dy/dx = 3x^2 - 6x - 9.
2. At a turning point dy/dx = 0: 3x^2 - 6x - 9 = 0.
3. Divide by 3: x^2 - 2x - 3 = 0.
4. Factorise: (x - 3)(x + 1) = 0, so x = 3 or x = -1.
5. Find the y values.
   When x = 3: y = 27 - 27 - 27 + 5 = -22.
   When x = -1: y = -1 - 3 + 9 + 5 = 10.
6. Classify using the second derivative: d2y/dx2 = 6x - 6.
   At x = 3: 18 - 6 = 12, which is positive, so this is a minimum.
   At x = -1: -6 - 6 = -12, which is negative, so this is a maximum.

**Answer: minimum point (3, -22); maximum point (-1, 10).**
