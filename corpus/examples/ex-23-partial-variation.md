## Question

y is partly constant and partly varies as x. When x = 2, y = 7; and when x = 5,
y = 13. Find the relation between y and x, and hence find y when x = 10.

## Solution

1. Partly constant and partly varying as x means y = a + bx.
2. Substitute the first pair: a + 2b = 7.
3. Substitute the second pair: a + 5b = 13.
4. Subtract: 3b = 6, so b = 2.
5. Substitute back: a + 4 = 7, so a = 3.
6. The relation is y = 3 + 2x.
7. When x = 10: y = 3 + 20 = 23.

**Answer: y = 3 + 2x, and y = 23 when x = 10.**
