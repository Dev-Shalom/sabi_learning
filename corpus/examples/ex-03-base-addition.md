## Question

Evaluate 1011 base two + 1101 base two, leaving your answer in base two.

## Solution

1. Add column by column from the right, carrying a group of two instead of a
   group of ten.
2. Units column: 1 + 1 = 2, which is 10 in base two. Write 0, carry 1.
3. Twos column: 1 + 0 + 1 (carried) = 2 = 10 in base two. Write 0, carry 1.
4. Fours column: 0 + 1 + 1 (carried) = 2 = 10 in base two. Write 0, carry 1.
5. Eights column: 1 + 1 + 1 (carried) = 3 = 11 in base two. Write 1, carry 1.
6. The final carry gives the leading 1.

**Answer: 11000 in base two.**

## Check in base ten

1011 base two is 11, and 1101 base two is 13. Their sum is 24, and 11000 in base
two is 16 + 8 = 24.
