## Question

Convert 3412 in base five to a number in base ten.

## Solution

1. Write the number in expanded form using powers of five. The digits from the
   right are 2, 1, 4 and 3, so the powers are 5^0, 5^1, 5^2 and 5^3.
2. 3412 base five = 3(5^3) + 4(5^2) + 1(5^1) + 2(5^0).
3. = 3(125) + 4(25) + 1(5) + 2(1).
4. = 375 + 100 + 5 + 2.
5. = 482.

**Answer: 482 in base ten.**

## Common mistake

Counting the powers from the left instead of the right. The rightmost digit is
always multiplied by the base to the power zero.
