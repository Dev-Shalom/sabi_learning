## Question

Use the matrix method to solve: 2x + 3y = 13 and x + 4y = 14.

## Solution

1. Write as AX = B, where A has first row 2, 3 and second row 1, 4; X is the
   column of x and y; B is the column 13 and 14.
2. Determinant of A = (2)(4) - (3)(1) = 5. It is not zero, so an inverse exists.
3. A inverse = one fifth times the matrix with first row 4, -3 and second row
   -1, 2.
4. X = A inverse B.
5. x = [4(13) + (-3)(14)] divided by 5 = (52 - 42)/5 = 10/5 = 2.
6. y = [(-1)(13) + 2(14)] divided by 5 = (-13 + 28)/5 = 15/5 = 3.

**Answer: x = 2, y = 3.**

## Check

2(2) + 3(3) = 4 + 9 = 13, and 2 + 4(3) = 14. Both equations are satisfied.
