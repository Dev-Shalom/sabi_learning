## Question

A student measured the length of a table as 2.4 m, but the actual length is
2.5 m. Find the percentage error in the measurement.

## Solution

1. Error = actual value minus measured value, taken as positive.
   Error = 2.5 - 2.4 = 0.1 m.
2. Percentage error = (error divided by the actual value) times 100.
3. = (0.1 divided by 2.5) times 100.
4. = 0.04 times 100 = 4.

**Answer: 4 per cent.**

## Common mistake

Dividing by the measured value instead of the actual value. The denominator is
always the true or exact value.
