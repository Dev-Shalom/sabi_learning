## Question

Simplify 3/(x - 2) - 2/(x + 1).

## Solution

1. The lowest common denominator is (x - 2)(x + 1).
2. Rewrite each fraction over that denominator:
   3(x + 1) over (x - 2)(x + 1), minus 2(x - 2) over (x - 2)(x + 1).
3. Combine the numerators: 3(x + 1) - 2(x - 2) = 3x + 3 - 2x + 4.
4. = x + 7.
5. So the expression is (x + 7) divided by (x - 2)(x + 1).

**Answer: (x + 7) over (x - 2)(x + 1), valid for x not equal to 2 and x not equal
to -1.**

## Common mistake

Forgetting that the minus sign applies to both terms of the second numerator.
Subtracting 2(x - 2) gives -2x + 4, not -2x - 4.
