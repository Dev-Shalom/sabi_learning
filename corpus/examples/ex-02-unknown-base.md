## Question

If 132 in base x is equal to 42 in base ten, find the value of x.

## Solution

1. Expand the left-hand side in base ten: 132 base x = 1(x^2) + 3(x) + 2.
2. Set it equal to 42: x^2 + 3x + 2 = 42.
3. Rearrange: x^2 + 3x - 40 = 0.
4. Factorise: (x + 8)(x - 5) = 0.
5. So x = -8 or x = 5.
6. A number base cannot be negative, so x = 5. Check that every digit used is
   less than 5: the digits are 1, 3 and 2, so base five is valid.

**Answer: x = 5.**

## Common mistake

Giving both roots. Always reject a base that is negative, zero, one, or not
greater than the largest digit in the number.
