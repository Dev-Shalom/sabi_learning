## Question

Solve the equation 3x^2 - 7x + 2 = 0.

## Solution

Using the formula

1. Here a = 3, b = -7, c = 2.
2. The discriminant b^2 - 4ac = 49 - 4(3)(2) = 49 - 24 = 25.
3. The square root of 25 is 5, so the roots are rational and the equation also
   factorises.
4. x = [7 plus or minus 5] divided by 6.
5. x = 12/6 = 2, or x = 2/6 = 1/3.

By factorisation

6. 3x^2 - 7x + 2 = (3x - 1)(x - 2), giving the same roots.

**Answer: x = 2 or x = 1/3.**

## Note

A perfect-square discriminant always means the quadratic factorises, so
factorisation would have been the faster route here.
