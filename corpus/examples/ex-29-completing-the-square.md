## Question

Express y = x^2 - 6x + 5 in the form (x + p)^2 + q, and hence state the minimum
value of y and the value of x at which it occurs.

## Solution

1. Take half the coefficient of x: half of -6 is -3.
2. Square it: (-3)^2 = 9.
3. Write x^2 - 6x as (x - 3)^2 - 9, since (x - 3)^2 expands to x^2 - 6x + 9 and
   the 9 must be removed again.
4. So y = (x - 3)^2 - 9 + 5 = (x - 3)^2 - 4.
5. A square is never negative, so the smallest value of (x - 3)^2 is 0, which
   happens when x = 3.
6. Then y = -4.

**Answer: y = (x - 3)^2 - 4; the minimum value of y is -4, occurring at x = 3.**

## Related

The roots of the equation are found by setting (x - 3)^2 = 4, giving x - 3 = 2 or
-2, so x = 5 or x = 1. The line of symmetry is x = 3.
