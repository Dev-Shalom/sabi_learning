## Question

In triangle ABC, b = 7 cm, c = 9 cm and angle A = 60 degrees. Find side a, correct
to two decimal places.

## Solution

1. Two sides and the included angle are given, so use the cosine rule.
2. a squared = b squared + c squared - 2bc cos A.
3. a squared = 49 + 81 - 2(7)(9) cos 60.
4. cos 60 = 0.5, so 2(7)(9)(0.5) = 63.
5. a squared = 130 - 63 = 67.
6. a = the square root of 67 = 8.185.

**Answer: a = 8.19 cm (to 2 decimal places).**

## Note

If cos A had come out negative, angle A would be obtuse. That is a valid result,
not an error.
