## Question

Solve the equation log x + log (x - 3) = 1.

## Solution

1. Combine the left side with the product law: log [x(x - 3)] = 1.
2. The logarithm is to base ten, and log 10 = 1, so x(x - 3) = 10.
3. Expand and rearrange: x^2 - 3x - 10 = 0.
4. Factorise: (x - 5)(x + 2) = 0, giving x = 5 or x = -2.
5. Test each root in the original equation. If x = -2 then log x is the logarithm
   of a negative number, which does not exist, so that root is rejected.

**Answer: x = 5.**

## Common mistake

Stopping at step 4. A logarithmic equation must always be checked against the
domain, because the logarithm of zero or of a negative number is undefined.
