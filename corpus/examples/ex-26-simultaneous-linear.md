## Question

Solve simultaneously: 3x + 2y = 16 and 5x - 3y = 14.

## Solution

1. Make the coefficients of y equal in size. Multiply the first equation by 3 and
   the second by 2.
2. 9x + 6y = 48, and 10x - 6y = 28.
3. Add the two equations, which eliminates y: 19x = 76.
4. x = 4.
5. Substitute into the first original equation: 3(4) + 2y = 16, so 2y = 4 and
   y = 2.

**Answer: x = 4, y = 2.**

## Check

5(4) - 3(2) = 20 - 6 = 14, which is the second equation.
