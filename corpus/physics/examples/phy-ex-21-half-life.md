## Question

A radioactive sample has a half-life of 5 days. If its initial count rate is 800 counts per minute, find the count rate after 20 days.

## Solution

1. First find how many half-lives have passed.
2. Number of half-lives = 20 / 5 = 4.
3. The count rate halves once per half-life, so divide by 2 that many times.
4. After each: 800 → 400 → 200 → 100 → 50.
5. Count rate = 50 counts per minute.
6. Radioactive decay is random: the half-life is a statistical average, not a promise about any one nucleus.

**Answer: 50 counts per minute**
