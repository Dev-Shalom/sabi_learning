## What the syllabus requires

Convert a number from one base to another. Perform the four operations in bases
other than ten. Solve simple equations in which the base is unknown, and
application problems.

## Converting to base ten

Write the number in expanded form using powers of the base, then add. For a number
in base b with digits d(n) ... d(1) d(0), the value in base ten is
d(n)*b^n + ... + d(1)*b^1 + d(0)*b^0.

For example 2134 in base five is 2*125 + 1*25 + 3*5 + 4 = 250 + 25 + 15 + 4 = 294
in base ten.

## Converting from base ten

Divide repeatedly by the new base and keep the remainders. The answer is the
remainders read from the last one upwards.

For example, to write 294 in base five: 294 divided by 5 is 58 remainder 4; 58
divided by 5 is 11 remainder 3; 11 divided by 5 is 2 remainder 1; 2 divided by 5
is 0 remainder 2. Reading upwards gives 2134 in base five.

## Operations in other bases

Add, subtract, multiply and divide exactly as in base ten, except that you carry
or borrow a group of b instead of a group of ten. In base five, 4 + 3 = 12,
because seven is one group of five and two units.

## Equations with an unknown base

Expand both sides in base ten and solve the resulting equation. If 24 in base b
equals 20 in base ten, then 2b + 4 = 20, so b = 8. Remember that every digit used
must be smaller than the base, which often rules out a root.

## Not on this syllabus

Binary arithmetic in the computing sense, two's complement, and bases above ten
that use letter digits are not examined in this paper.
