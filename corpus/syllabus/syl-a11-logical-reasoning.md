## What the syllabus requires

Simple true and false statements. Negation, conjunction, disjunction and
implication. The converse, inverse and contrapositive of an implication. Simple
valid arguments and the use of Venn diagrams to test them.

## Statements

A statement is a sentence that is either true or false, but not both. The negation
of p, written not p, has the opposite truth value.

## Connectives

p and q is true only when both are true. p or q is true when at least one is true.
The implication if p then q is false only in one case: when p is true and q is
false.

## Related forms

For the implication if p then q:
the converse is if q then p;
the inverse is if not p then not q;
the contrapositive is if not q then not p.

Only the contrapositive is always logically equivalent to the original statement.
A very common error in the exam is treating the converse as equivalent.
