## What the syllabus requires

Types of mapping: one-to-one, one-to-many, many-to-one and many-to-many. Domain,
co-domain and range. Function notation and the evaluation of a function at a given
value. Inverse of a simple one-to-one function.

## Relation and function

A relation pairs elements of one set with elements of another. A relation is a
function when every element of the domain has exactly one image. So one-to-one and
many-to-one mappings are functions; one-to-many is not.

## Notation

If f(x) = 3x - 5, then f(4) means substitute 4 for x, giving 7. The domain is the
set of inputs, the range is the set of outputs that actually occur.

## Inverse

To find the inverse of a one-to-one function, write y = f(x), make x the subject,
then swap the letters. The inverse of f(x) = 3x - 5 is f inverse of x = (x + 5)
divided by 3.

## Composite functions

fg(x) means apply g first and then f. The order matters.
