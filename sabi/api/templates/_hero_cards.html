{# The hero deck. Four sheets on a desk, one face up, cycling. Each is the same object the product actually produces: a worked answer whose every claim opens to the syllabus line behind it. Honesty, because this is the one page where it would be easiest to cheat: only Mathematics is in the corpus today, so only that card is a real answer and it says so. The other three are marked "being written" and are showing the *format*, not claiming to be answers Sabi can currently give. When their documents land the badge changes and nothing else has to. Without JavaScript only the first card is rendered at all, so the hero is a single worked answer -- a deck that cannot deal itself should not show four cards piled on one another. With JavaScript every card occupies the same grid cell, including the ones you cannot see. That is deliberate: the window is then as tall as the tallest card and dealing a new one cannot change the height of the page. Hiding them with `hidden` took them out of the grid and made the whole page jump each time the deck turned over. #}
